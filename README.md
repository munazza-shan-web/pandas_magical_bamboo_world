# Panda's Magical Bamboo World (v2)

A cozy 2D panda game for kids and families (3+), built with Flutter. Everything is drawn in code, no downloads or ads.

## Game modes
- **Adventure**: side-scrolling run through 5 bamboo worlds (day, golden afternoon, sunset, moonlit, misty). Tap to jump, tap again for a double jump, collect bamboo and stars, dodge rocks and logs. 3 hearts, 1-3 stars per level, levels unlock as you go.
- **Panda Home**: look after Bao. Feed, play, tuck into bed, tap for cuddles. Meters drop over time, even while the app is closed.
- **Badges**: 9 rewards to earn. Unlock a bow (20 bamboo) and a crown (8 stars) for Bao.

## Run
1. Open this folder in VS Code, then in PowerShell: `Set-ExecutionPolicy -Scope Process Bypass` and `.\scripts\setup_and_run.ps1`
2. Or run `flutter pub get` then `flutter run -d chrome`.
3. Release APK: `flutter build apk --release`

Progress is saved on the device only. Review the legal pages before publishing.
